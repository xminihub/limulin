# limulin

A TUI for [dsh](https://github.com/xminihub) and others, built with [OpenTUI](https://opentui.com).

## Install

```bash
brew tap xminihub/tap
brew install lim
```

Or `npm install -g limulin` (Node >= 22) / `bun add -g limulin`. Standalone binaries for macOS, Linux and Windows are on the [releases page](https://github.com/xminihub/limulin/releases/latest).

## Usage

```bash
lim            # launch the TUI
lim --help
```

## Development

```bash
bun install
bun run dev
bun test
```
