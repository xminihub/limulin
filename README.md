# limulin

A TUI for [dsh](https://github.com/xminihub) and others.

**Repository:** https://github.com/xminihub/limulin
**Issues:** https://github.com/xminihub/limulin/issues

## Install

```bash
bun add limulin
```

Or from source:

```bash
git clone https://github.com/xminihub/limulin.git
cd limulin
bun install
```

## Development

Run the entrypoint:

```bash
bun run index.ts
```

Type check:

```bash
bun check
```

Format:

```bash
bun fmt
```
